# AGENTS.md

This repository packages an agent skill for embedded MCU firmware development.

If you are an AI coding agent:

1. Read `skill/mcu-ai-firmware/SKILL.md` first.
2. Load only the `references/*.md` files relevant to the task.
3. When working inside a firmware repository, prefer that repository's own
   `CLAUDE.md` / `AGENTS.md` / docs over this generic guidance.
4. Never modify this skill repository's published history to fit one project;
   fork or copy it instead.

Human readers: see `README.md`.
